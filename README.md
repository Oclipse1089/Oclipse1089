# 🪐 VibeGrid — Turn Your Aesthetic Into Your Storefront

VibeGrid is a minimalist, visual-first micro-platform designed for modern digital creators, curators, and affiliate marketers. Instead of relying on traditional, text-heavy "link-in-bio" tools, VibeGrid empowers users to build interactive, Pinterest-style **Shoppable Lookbooks** that capture visual attention and streamline product discovery.

[Live Demo](https://yourusername.github.io/vibegrid) · [Report Bug](https://github.com/yourusername/vibegrid/issues) · [Request Feature](https://github.com/yourusername/vibegrid/issues)

---

## ✨ Features

- **Editorial Grid Engine:** An adaptive, fluid layout built to showcase high-end photography without messy layout clutter.
- **Interactive Hotspot Tagging:** Hover over any visual asset to trigger clean, elegant product overlays containing purchase info and affiliate links.
- **Cohesive Theme Matching:** Easily match your platform's UI color codes to your active Instagram or Pinterest mood boards.
- **Ultra-Responsive Architecture:** Engineered for maximum speed and flawless layouts across desktop monitors, tablets, and mobile screens.

---

## 🎨 Design Philosophy & Tech Stack

VibeGrid is built on a dark-mode minimalist aesthetic inspired by high-end editorial magazines.

- **Typography:** Bold serif headers combined with sharp, high-legibility sans-serif text blocks.
- **Color Palette:** Pure dark backgrounds (`#0F0F0F`), clean stark whites (`#F5F5F5`), and soft glowing accent tones.
- **Technologies Used:** HTML5, CSS3 (Custom Variables, CSS Grid, and Flexbox), and Vanilla JavaScript for smooth micro-interactions.
